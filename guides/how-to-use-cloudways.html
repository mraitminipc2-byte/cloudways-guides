How to Use Cloudways: Deploy, Access, and Migrate WordPress

Based on the video "how to use Cloudways 2026" by MR AIT · watch on YouTube

If you've ever watched a website crash during a traffic spike on shared hosting, this is the lesson that fixes it. The core idea: raw VPS providers like Vultr and DigitalOcean offer incredible speed but expect command-line skills. Cloudways is the bridge — top-tier server performance with a beginner-friendly dashboard.

Deploy a WordPress server on DigitalOcean

From the dashboard, launch a new application: choose WordPress, pick DigitalOcean as the provider (the best value tier), and select the server location closest to your visitors. The server provisions in a couple of minutes — no terminal, no stack installation.

Access your staging site and wp-admin

Every application gets a temporary staging URL the moment it's created, so you can build and test before connecting your real domain. The video shows where to find the WordPress admin credentials and how to log in to wp-admin with one click.

Migrate your old site with All-in-One WP Migration

This is the part most people fear, and it's free:

  1. Install the All-in-One WP Migration plugin on your old site and export the whole site to a file.
  2. Install the same plugin on your new Cloudways WordPress application.
  3. Import the file — content, theme, plugins, and settings come over together.
  4. Fix the two hardcoded things: update your DNS/domain to point at the new server and re-save permalinks.

Test before you switch

Use the staging URL to click through the migrated site — pages, forms, images, and plugins — before changing DNS. When it looks right, point your domain and you're live on the new server.
