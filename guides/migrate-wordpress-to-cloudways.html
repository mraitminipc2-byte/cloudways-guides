How to Migrate WordPress to Cloudways (Free Plugin Method)

A reference guide based on MR AIT’s Cloudways video course

Moving a live site feels risky until you’ve done it once with a staging URL in the middle. This is the full flow from Lesson 4, step by step.

Before you start

You need a Cloudways account with a WordPress application deployed (Lesson 2 covers the launch). Every application gets a temporary staging URL immediately — that URL is what makes this migration zero-downtime.

Step 1: Export from the old site

  1. Install the free All-in-One WP Migration plugin on your existing WordPress site.
  2. Go to its Export screen and download the full site file — content, media, themes, plugins, and settings in one package.

Step 2: Import on Cloudways

  1. Open your new Cloudways application’s staging URL and install the same plugin.
  2. Import the file. The import overwrites the fresh WordPress install with your site.
  3. Log into wp-admin with your old credentials and re-save your permalinks.

Step 3: Test on staging

  • Click through pages, posts, images, menus, and forms.
  • Check that plugins behave and no hardcoded old-domain URLs break assets.
  • Test on mobile — or with a proper device profile if you’re thorough.

Step 4: Flip the domain

  1. Update your domain’s DNS A record to your new server’s public IP (shown in the Cloudways application panel).
  2. Issue the free SSL certificate from the application’s SSL tab once DNS resolves.
  3. Watch traffic for a day before closing the old hosting account — then cancel it and enjoy the speed.

Frequently asked questions

How much does migrating to Cloudways cost?

The plugin method shown here is free — All-in-One WP Migration has no cost for standard exports and imports. Your only cost is the server time, which the trial credits can cover.

How long will my site be down?

Zero, if you follow the staging flow: the old host keeps serving visitors until you switch DNS, and DNS propagation is the only transition window.

What if my site is bigger than the upload limit?

All-in-One WP Migration lets you export in chunks, and the video’s flow works the same — split the export, import the parts in order.

Do I need to reinstall my theme and plugins?

No — the import carries the entire site: themes, plugins, media, users, and settings.
